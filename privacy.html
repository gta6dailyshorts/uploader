Privacy Policy

Last updated: November 17, 2026

GTA6dailyshorts uploader ("the app") is a personal tool run by the owner of the GTA6dailyshorts YouTube channel. Its only user is the owner.

What data the app uses

  • A Google OAuth token with the youtube.upload permission, used only to upload videos to the owner's own channel.
  • The video files, titles, descriptions and tags that the owner chooses to upload.

How data is stored

The token is stored only on the owner's own computer. The app has no server and no database, and it does not collect, sell, or share any personal data with third parties.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
